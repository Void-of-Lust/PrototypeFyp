# PrototypeFyp

This branch combines the PrototypeFyp project with the Prototype-0 codebase.

## Overview
PrototypeFyp is the main project and is primarily HTML/Python-based.
Prototype-0 is a Python-first repository with additional native/C++ components.

## Combined Project
This merge brings together:
- the web/application structure from PrototypeFyp
- the Python logic and codebase from Prototype-0

## Purpose
The goal of this branch is to create a unified Chimera repository that preserves both codebases while enabling further development on a single branch.

## Setup
1. Clone the repository
2. Install dependencies
3. Run the project entry point

## Notes
This branch is a merge of two independent repositories and may require additional conflict resolution in other files.
